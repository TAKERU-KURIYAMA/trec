# Message システム機能一覧

## 1. 実装済み機能

### 1.1 認証・ユーザー管理機能

#### ✅ ユーザー登録
- メールアドレス・パスワード・名前での登録
- パスワード強度チェック（8文字以上、大小英数字混在）
- メールアドレス重複チェック
- BCryptによるパスワードハッシュ化
- ユーザーID自動生成（USR_プレフィックス）

#### ✅ ログイン/ログアウト
- メールアドレス・パスワードでのログイン
- JWT（JSON Web Token）による認証
- トークン有効期限: 7日間
- ログイン状態保持オプション
- セキュアなログアウト処理（トークン無効化）

#### ✅ トークン管理
- アクセストークン・リフレッシュトークン
- 自動トークン更新機能
- XOR暗号化によるローカルストレージ保護
- トークン期限切れ前の自動更新

#### ✅ 管理者機能
- 管理者権限でのユーザー作成
- ユーザー一覧表示
- ユーザー情報更新（実装中）
- ユーザー削除（実装中）

### 1.2 トレーニングメニュー管理

## 3. 技術的実装詳細

### 3.1 フロントエンド実装
- **Vue 3 Composition API**: リアクティブな状態管理
- **Nuxt 3**: SSR/SSG対応、自動ルーティング
- **TypeScript**: 型安全性の確保
- **Pinia**: グローバル状態管理
- **TailwindCSS**: ユーティリティファーストCSS

### 3.2 バックエンド実装
- **ASP.NET Core 8.0**: 高性能Web API
- **Entity Framework Core**: ORM
- **PostgreSQL**: リレーショナルデータベース
- **JWT認証**: セキュアな認証システム
- **Swagger/OpenAPI**: API文書化

### 3.3 モバイルアプリ実装
- **React Native**: クロスプラットフォーム開発
- **Zustand**: 状態管理
- **React Navigation**: 画面遷移管理
- **AsyncStorage**: ローカルデータ保存
- **React Native Reanimated**: 高性能アニメーション

### 3.4 インフラ・DevOps
- **Docker**: コンテナ化
- **GitHub Actions**: CI/CD自動化
- **Nginx**: リバースプロキシ
- **Prometheus/Grafana**: 監視・可視化
- **自動バックアップ**: 日次実行
