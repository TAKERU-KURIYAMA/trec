## 📱 プラットフォーム対応

### Web アプリケーション
- **フレームワーク**: Vue 3 + Nuxt 3
- **言語**: TypeScript
- **スタイル**: TailwindCSS
- **対応ブラウザ**: Chrome, Firefox, Safari, Edge

### モバイルアプリ
- **フレームワーク**: React Native
- **対応OS**: iOS 13+, Android 8+
- **ストア**: App Store, Google Play

### API
- **フレームワーク**: ASP.NET Core 8.0
- **データベース**: PostgreSQL 15
- **認証**: JWT + OAuth 2.0
