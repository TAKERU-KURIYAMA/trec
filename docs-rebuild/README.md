## 🆘 トラブルシューティング

### よくある問題

#### VitePressが起動しない
```bash
# Node.jsバージョン確認
node --version  # 18+ 必須

# 依存関係リセット
rm -rf node_modules package-lock.json
npm install
```

#### ページが表示されない
1. ファイルパス確認
2. マークダウン記法確認
3. config.js設定確認

#### スタイルが適用されない
1. CSS記法確認
2. ファイルパス確認
3. ブラウザキャッシュクリア

### サポート体制
- **30分ルール**: 30分で解決できない問題は記録して後回し
- **エスカレーション**: 作業ブロッカーは方針見直し
- **ドキュメント化**: 解決方法を必ず記録
