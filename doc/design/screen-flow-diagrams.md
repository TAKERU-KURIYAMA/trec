# 画面フロー設計図

## 概要
このドキュメントはトレーニング管理アプリケーションの画面フローを示します。
Webフロントエンド(Nuxt.js)とモバイルアプリ(React Native)の両方の画面遷移を記載しています。

## システム構成
```
[Frontend (Nuxt.js)] ←→ [API (ASP.NET Core)] ←→ [Database (SQL Server)]
[Mobile App (React Native)] ←→ [API (ASP.NET Core)] ←→ [Database (SQL Server)]
```

## 3. API連携フロー

### 3.1 データフロー図
```
[Frontend/Mobile] ──HTTP Request──► [API Controller] ──► [Service Layer] ──► [Database]
                 ◄──HTTP Response─── [API Response] ◄── [Business Logic] ◄── [Entity Models]
```

### 3.2 主要API エンドポイント
```
Authentication:
POST /api/Account/GetToken      (ログイン)
POST /api/Account/PostUser      (ユーザー登録)

Training:
GET  /api/training/menu         (メニュー一覧取得)
GET  /api/Training/GetRecord    (トレーニング履歴取得)
GET  /api/Training/GetDaily     (日別レコード取得)
POST /api/Training/PostRecord   (トレーニング記録保存)
DELETE /api/Training/DeleteRecord/{id} (レコード削除)

System:
GET  /api/version               (バージョン情報)
```
